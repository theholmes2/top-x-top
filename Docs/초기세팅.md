# 탑x탑 최초 세팅 — 2026-11-02

## 적용 범위

사용자가 생성한 Unity 프로젝트의 환경·문서·폰트만 준비했다. 게임 CS, 샘플 게임, 전투 골격, DI 조립 코드, UI 화면은 작성하지 않았다. 탑오브탑은 참고용으로 보존한다.

## 기본규칙과 작업 방식

- 루트 AGENTS.md에 기존 기본규칙 0~15를 계승하고 탑x탑 제작 방식 16항을 추가했다.
- CS 하나·요소 하나의 역할·입출력·연결을 사용자 검토 후 승인 범위만 구현한다.
- 읽기 쉬운 줄바꿈·중괄호·들여쓰기 규칙을 명시하고 .editorconfig를 추가했다. 자동 서식만으로 모든 긴 식이 나뉜다고 보장하지 않으므로 실제 파일을 확인한다.
- Snapshot을 모든 계산에 통째로 전달하거나 이전 게임 코드를 일괄 복사하지 않는다.
- 빈 Assets/Scripts, Assets/Configs, Assets/Prefabs 폴더를 준비했다. 구체적인 하위 게임 구조는 검토 전 만들지 않았다.

## 환경

- Unity 6000.3.19f1, 기존 2D URP 템플릿을 유지했다.
- 프로젝트 경로: E:/GameDev/unity-main-portfolio/top x top
- 해당 프로젝트의 Unity Pipeline 연결 ready 확인. 모든 Editor 명령에 이 프로젝트 경로를 명시했다.
- 텍스트 직렬화 ForceText 및 Visible Meta Files 설정.
- Input System·uGUI·2D·URP 등 기존 템플릿 패키지는 유지했다.
- VContainer·R3·DOTween·UGS/IAP/Diagnostics의 추가 설치·기능 연동은 아직 하지 않았다. 필수 기술 목표는 AGENTS.md에 유지하며 각 요소 검토 시 적용한다.
- 클라우드 프로젝트·로그인·Player ID·운영 설정을 이전 프로젝트에서 가져오지 않았다.

## 한글 기본 폰트

Assets/Art/Fonts/NotoSansKR 아래에 다음을 배치했다.

- NotoSansKR-VariableFont_wght.ttf: 탑오브탑에 보관된 동일 폰트 원본을 재사용.
- OFL.txt: 원본에 동봉된 SIL Open Font License 유지.
- NotoSansKR Latin SDF.asset: ASCII 95글자를 미리 생성한 정적 1024×1024 아틀라스, 샘플링72·패딩7.
- NotoSansKR Korean Dynamic SDF.asset: 동적 한글 fallback, 아틀라스1024×1024·샘플링42·패딩4. 필요한 글자만 추가하며 Multi Atlas를 허용하므로 장기 메모리 상한은 별도 측정한다.

공식 TMP Essential Resources만 가져와 필요한 셰이더·설정·기본 리소스를 준비했다. TMP Settings 기본 폰트를 NotoSansKR Latin SDF로 지정하고 그 폰트의 fallback을 Korean Dynamic SDF로 연결했다.

한글 fallback의 Clear Dynamic Data On Build를 켰다. 한글·게임 UI 문구·숫자의 중복 제외45글자 추가 성공을 확인한 뒤 시험 중 생성된 동적 글자를 비워 저장했다. 정적 ASCII는95글자, 동적 저장 글자는0개다. 새 TMP Text는 기본 폰트를 사용하고 한글을 fallback에서 찾는다.

글리프 존재 및 설정 연결을 검사했으며 실제 화면 배치·기기 빌드·모든 유니코드 글자·혼합 문자의 시각 품질을 검증한 것은 아니다. 임의의 픽셀 폰트·게임 아트는 추가하지 않았다.

## Git과 검증 범위

변경 전 Git 상태를 확인했다. 이미 있던 HubForceResolve 관련 삭제 및 URP/ProjectSettings 변경은 복원하거나 정리하지 않았다. 기존 .gitignore·.gitattributes를 유지했다. 브랜치 변경·원격 연결·스테이징·커밋·푸시는 하지 않았다.

게임 CS를 생성하지 않았고 Scene은 변경하지 않았다. 공식 TMP 리소스 임포트가 만든 설정·meta 변경은 폰트 환경 세팅으로 구분한다. 해당 프로젝트 Unity 설정 조회와 폰트 생성 API 검증만 수행했고 Play 모드는 시작하지 않았다.
