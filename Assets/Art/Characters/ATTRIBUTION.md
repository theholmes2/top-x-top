# 몬스터 이미지 출처

이전 top of top 프로젝트의 출처 기록을 바탕으로 필요한 이미지만 가져왔다. 이전 프로젝트 코드·프리팹은 복사하지 않았다. 원본 PNG의 픽셀은 유지하고 Sprite Editor 메타데이터로 정지 프레임 하나만 선택한다.

- Adventurer: rvros — https://rvros.itch.io/animated-pixel-hero (`adventurer-idle-00.png`, 정지 이미지 한 장)
- Slime: rvros — https://rvros.itch.io/pixel-art-animated-slime (`slime-idle-0.png`)
- Rat: PolishedStone — https://polishedstone.itch.io/animated-pixel-enemies (`rat base v2-Sheet.png`, 동봉 README.txt 보존)
- Goblin: LuizMelo — https://luizmelo.itch.io/monsters-creatures-fantasy (`Idle.png`)
- Golem: MonoPixelArt — https://monopixelart.itch.io/golems-pack (`Golem_1_idle.png`, 무료 Blue/No_Swoosh_VFX)
- Wolf: 사용자가 승인한 임시 실루엣. 이번 작업에서 다각형으로 만든 정지 이미지이며 최종 아트가 아니다.

게임 내 사용과 에셋 원본 재배포는 별개이며 모두 CC0라고 취급하지 않는다. 기존 원본 기록은 이전 프로젝트 `ArtSources/Downloaded`를 참고한다. 이번 작업에서는 커밋·공개 배포하지 않았다.
